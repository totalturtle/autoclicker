### 설치부터 첫 자동 클릭까지, 3분

**1단계. 접근성 권한 켜기**

앱을 처음 열면 권한 두 개를 안내합니다. 자동 클릭의 핵심은 **접근성 서비스**입니다. 안드로이드가 "화면을 대신 터치하는 기능"을 이 권한으로만 허용하기 때문에, 루팅 없는 오토클리커는 전부 이 방식을 씁니다. 설정 → 접근성 → 설치된 앱 → 자동탭 → 사용으로 켜주세요.

**2단계. 다른 앱 위에 표시 허용**

게임이나 다른 앱 위에 떠 있는 작은 조작 패널(오버레이)을 쓰기 위한 권한입니다. 이게 있어야 앱을 왔다 갔다 하지 않고 바로 시작·정지할 수 있습니다.

**3단계. 누를 위치 찍기**

세 가지 방법 중 편한 걸 쓰면 됩니다.

- **좌표 추가**: 포인트를 추가하고 화면에 생긴 마커를 원하는 자리로 드래그
- **터치 녹화**: 평소처럼 화면을 터치하면 그 순서 그대로 포인트로 저장
- **직접 입력**: X, Y 좌표를 숫자로 입력

**4단계. 딜레이와 반복 정하기**

포인트마다 "다음 동작까지 얼마나 기다릴지"를 정하고, 전체 반복을 무한 또는 횟수·시간으로 지정합니다. 그다음 재생 버튼만 누르면 끝입니다. 정지는 플로팅 패널의 정지 버튼이나 볼륨 버튼 핫키로 즉시 가능합니다.

---

### 실제로 많이 쓰는 설정 세 가지

**① 한 자리만 빠르게 연타**

포인트 1개 + 딜레이 짧게 + 무한 반복. 방치형 게임의 수집 버튼이나 연타가 필요한 화면에 쓰는 가장 단순한 조합입니다.

**② 여러 버튼을 순서대로 순회**

"상자 열기 → 확인 → 닫기 → 다음" 처럼 자리가 다른 버튼을 순서대로 눌러야 할 때는 포인트를 그 순서대로 등록하면 됩니다. 포인트마다 딜레이를 따로 줄 수 있어서, 로딩이 긴 구간만 길게 잡아둘 수 있습니다. 목록에서 드래그로 순서도 바꿀 수 있고요.

**③ 특정 화면일 때만 누르기 (조건부)**

색상 트리거를 걸면 "지정한 좌표가 이 색일 때만" 그 포인트를 실행합니다. 버튼이 활성화됐을 때만 누르거나, 팝업이 떴을 때만 닫는 식으로 쓸 수 있습니다. 조건이 안 맞으면 건너뛸지, 몇 번 더 기다렸다 다시 볼지도 고를 수 있습니다.

### 다른 오토클리커와 다른 점

**사람처럼 들쭉날쭉하게 누르기**
딜레이와 좌표에 랜덤 오차를 줄 수 있습니다. 1초마다 정확히 같은 픽셀을 누르는 기계적인 패턴 대신, 매번 조금씩 다른 타이밍과 위치로 터치합니다.

**프로필 + 앱 연동 자동 전환**
게임마다, 작업마다 세팅을 프로필로 저장해두고 불러 쓸 수 있습니다. 프로필에 앱을 연동해두면 **그 앱을 켜는 순간 해당 프로필이 자동으로 로드**되고 조작 패널도 같이 떠서, 매번 설정을 고를 필요가 없습니다. 프로필은 JSON 파일로 내보내고 가져올 수 있어 기기를 바꿔도 그대로 옮겨집니다.

**화면을 가리지 않는 조작 패널**
플로팅 패널은 기본적으로 최소화 상태로 떠 있고, 필요할 때만 펼칩니다. 실행 중에는 좌표 마커도 자동으로 숨겨져서 게임 화면을 가리지 않습니다.

**빠른 설정 타일**
알림창을 내려 타일 하나로 시작·정지할 수 있습니다. 앱을 다시 열 필요가 없습니다.

### 자주 묻는 질문

**루팅해야 하나요?**
아닙니다. 접근성 서비스만 켜면 됩니다. PC 연결이나 ADB 설정도 필요 없습니다.

**접근성 권한을 주면 화면 내용이 새나가나요?**
자동탭은 접근성 서비스를 "화면을 터치하는 용도"로만 사용합니다. 클릭 포인트·프로필·설정은 전부 기기 내부에만 저장되고 외부 서버로 전송하지 않습니다. 권한은 설정에서 언제든 해제할 수 있습니다. ([개인정보처리방침](https://play.google.com/store/apps/details?id=com.realbtob.autoclicker))

**화면을 꺼도 작동하나요?**
아니요. 접근성 서비스 기반 자동 터치는 화면이 켜져 있어야 동작합니다. 화면 꺼짐 시간을 길게 설정해두세요.

**게임에서 써도 되나요?**
기술적으로는 동작하지만, **자동화 도구 사용을 금지하는 게임이 많습니다.** 계정 제재는 각 게임 운영 정책에 달려 있으니 해당 게임 약관을 꼭 확인하고 본인 판단으로 사용하세요.

**엉뚱한 곳을 눌러요 / 마커가 안 보여요**
좌표는 화면 방향마다 다릅니다. 가로모드에서 만든 설정을 세로모드에서 불러오면 좌표가 화면 밖으로 나가 마커도 안 보이고 터치도 안 먹습니다. **설정을 만들 때와 같은 방향으로 돌려놓고** 불러오세요.

**배터리를 많이 먹나요?**
클릭이 실행되는 동안만 동작하고, 대기 중에는 작은 알림 하나만 유지됩니다. 다만 화면이 계속 켜져 있어야 하므로 그만큼은 소모됩니다.

**아이폰에서도 되나요?**
안드로이드 전용입니다. iOS는 시스템 정책상 이런 방식의 자동 터치를 허용하지 않습니다.

### 쓰기 전에 알아둘 점

- 안드로이드 8.0 이상에서 동작합니다.
- 자동 클릭 중에는 화면이 실제로 터치되므로, 결제 버튼이나 삭제 버튼 근처 좌표는 특히 주의해서 설정하세요.
- 삼성 기기 일부 앱은 패키지명이 달라서(예: 포켓몬GO) 앱 연동 설정 시 정확한 패키지명을 넣어야 합니다.
- 접근성 권한이 꺼지면 자동 클릭도 멈춥니다. 배터리 최적화에서 앱이 종료되지 않도록 예외 처리해두면 안정적입니다.
