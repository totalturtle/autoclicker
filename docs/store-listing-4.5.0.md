# 플레이스토어 등록정보 문구 — 자동탭(오토클릭) 4.5.0

Play Console → 사용자 늘리기 → 스토어 등록정보 → 기본 등록정보 수정

(간단한 설명 80자 / 자세한 설명 4,000자 제한)

---

## 1. 앱 이름 (30자 제한)

현재: `자동탭(오토클릭)`

**바꾸는 것을 권합니다.** Play 검색은 앱 이름의 단어를 가장 크게 보는데, 사람들이
실제로 치는 "오토클리커 / 자동클릭 / 자동터치"가 이름에 없습니다.

```
자동탭 - 오토클리커 자동클릭
```

```
오토클리커 - 자동탭 자동 터치
```

브랜드를 유지하면서 검색어를 넣은 형태입니다. 키워드 나열이 아니라 정책에도 걸리지 않습니다.

## 2. 간단한 설명 (80자 제한)

**권장안**

```
루팅 없이 화면을 자동으로 터치. 위치·간격만 정하면 끝나는 간단 모드 지원.
```

**대안**

```
오토클리커 · 자동 터치 매크로. 터치를 녹화해 그대로 반복하세요. 루팅 불필요.
```

---

## 3. 자세한 설명 (4,000자 제한)

```
자동탭(오토클릭)은 화면의 원하는 위치를 자동으로 터치해주는 안드로이드 오토클리커입니다.
루팅이나 PC 연결 없이, 접근성 권한만 켜면 바로 쓸 수 있습니다.


■ 처음이라면, 간단 모드

버튼 몇 개로 끝납니다.

1. 한 곳 반복 / 여러 곳 순서대로 중에서 고르기
2. 쓰려는 앱을 열고 화면 위 + 버튼으로 누를 자리 지정
3. 간격과 반복 횟수를 정하고 시작

지정한 자리에는 동그란 표시가 떠서 어디를 찍었는지 눈으로 확인됩니다.
실행하면 앱은 뒤로 물러나고, 멈추기 버튼만 화면 위에 남습니다.


■ 터치 녹화

평소처럼 화면을 터치하기만 하세요. 누른 순서와 간격을 그대로 기억했다가 똑같이
반복해 줍니다. 쓰려는 앱을 띄운 상태에서 화면 위 ● 버튼으로 녹화를 시작합니다.


■ 모든 기능 모드

더 세밀하게 다루고 싶을 때 쓰는 화면입니다.

• 멀티 포인트 — 최대 50개의 위치를 순서대로 실행
• 제스처 — 탭, 길게 누르기, 스와이프(꺾임 경유점 포함)
• 포인트별 설정 — 딜레이, 반복 횟수, 반복 간 간격
• 딜레이 단위 — ms · 초 · 분 중에서 선택
• 랜덤 오차 — 딜레이와 좌표를 조금씩 흔들어 더 자연스럽게
• 색상 트리거 — 지정한 색이 보일 때만 누르는 조건부 실행
• 이미지 영역 트리거 — 화면 영역을 캡처해 일치할 때만 실행
• 전체 반복 — 무한 / 횟수 지정 / 시간 지정
• 프로필 — 설정을 저장하고 불러오기, 파일로 내보내기·가져오기
• 앱 연동 — 연동한 앱을 실행하면 그 프로필을 자동으로 불러오기
• 빠른 조작 — 알림창 타일, 볼륨 키로 시작·정지


■ 이런 분께

• 게임 반복 퀘스트나 파밍을 자동화하고 싶은 분
• 출석 체크처럼 같은 자리를 계속 눌러야 하는 분
• 여러 버튼을 정해진 순서로 눌러야 하는 분
• 앱 테스트용으로 같은 터치를 반복해야 하는 분


■ 무료로 쓸 수 있는 범위

• 위치 3개까지, 연속 실행 3시간까지
• 탭 · 길게 누르기 · 터치 녹화 · 랜덤 딜레이 · 프로필 2개
• 광고를 보면 24시간 동안 위치 4개, 녹화, 연속 실행 24시간이 열립니다
  (원할 때 버튼을 눌러야 재생되며, 갑자기 뜨지 않습니다)

■ 프리미엄 (일회 결제)

위치·프로필 개수 제한 해제, 스와이프, 색상·이미지 트리거, 루프 종료 조건,
프로필 퀵 전환, 광고 제거. 구독이 아니라 한 번 결제하면 끝입니다.


■ 알아두실 점

• 자동 클릭은 화면이 켜져 있을 때만 동작합니다
• 좌표는 화면 방향마다 다릅니다. 가로에서 만든 설정은 가로에서 불러오세요
  (방향이 다르면 앱이 알려 줍니다)
• 자동화 도구 사용을 제한하는 서비스가 있습니다. 이용 약관을 확인하고 사용해 주세요
• Android 8.0 이상 지원


[접근성 서비스 사용 고지]
본 앱은 사용자가 지정한 화면 위치를 자동으로 탭/스와이프하는 자동 클릭
기능을 제공하기 위해 Android 접근성 서비스(AccessibilityService API)를
사용합니다.

• 사용 목적: 사용자가 설정한 좌표·순서·반복에 따라 화면을 자동으로
  터치(탭, 롱프레스, 스와이프)하는 동작을 수행하기 위함입니다.
• 접근성 서비스는 사용자가 직접 활성화한 경우에만 동작하며, 자동 클릭
  실행에만 사용됩니다.
• 본 앱은 접근성 서비스를 통해 개인정보나 화면의 콘텐츠를 수집·저장·
  전송하지 않습니다.
• 접근성 권한은 설정에서 언제든지 해제할 수 있습니다.
```
