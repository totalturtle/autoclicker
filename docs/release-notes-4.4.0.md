# 플레이스토어 업데이트 문구 — 4.4.0 (versionCode 11)

## 권장안 (그대로 붙여넣기)

[4.4.0 업데이트]

• 딜레이를 ms뿐 아니라 초·분 단위로 입력 — 10분 대기도 간단하게
• 같은 포인트를 반복할 때의 간격을 따로 설정 가능
• 프리미엄 사용자에게 광고가 표시되던 문제 수정
• 프로필을 같은 이름으로 저장하면 중복 생성 대신 덮어쓰기 확인
• 현재 프로필 표시·전환 정확도 개선 (알림창 ◀▶, 퀵버튼)
• 프로필 저장·삭제·순서 변경이 오버레이에 즉시 반영
• 다른 화면 방향에서 만든 프로필을 불러오면 안내 메시지 표시
• 설정이 섞여 저장되던 문제, 앱이 꺼진 상태에서 프로필이 불러와지지 않던 문제 수정

## 짧은 버전 (핵심만)

[4.4.0 업데이트]

• 딜레이를 초·분 단위로 입력 가능
• 반복 간 딜레이 별도 설정 추가
• 프리미엄 사용자 광고 노출 문제 수정
• 프로필 덮어쓰기 확인 추가 (중복 저장 방지)
• 현재 프로필 표시·전환 오류 수정
• 화면 방향이 다른 프로필 불러올 때 안내 추가

## 메모

- Play Console "변경사항" 입력란은 언어별 500자 제한
- 이전 등록 버전: 4.3.2 (2026-06-26) → 이번 4.4.0 사이에 4.3.3은 스토어에 올리지 않았으므로,
  4.3.3에서 들어간 "반복 간 딜레이" 기능도 이번 문구에 포함했다
