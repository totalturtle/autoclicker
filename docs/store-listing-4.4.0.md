# 플레이스토어 등록정보 문구 — 자동탭(오토클릭) 4.4.0

Play Console → 기본 스토어 등록정보에 그대로 붙여넣는 문구입니다.
(간단한 설명 80자 / 자세한 설명 4,000자 제한)

---

## 1. 간단한 설명 (80자 제한)

**권장안**

```
루팅 없이 화면을 자동 터치하는 오토클릭 앱. 좌표 여러 개를 순서대로 반복 클릭하세요.
```

**대안**

```
오토클리커 · 자동 터치 매크로. 탭·스와이프를 녹화하고 반복 실행하세요. 루팅 불필요.
```

```
게임 반복 터치를 자동으로. 멀티 포인트 자동 클릭, 터치 녹화, 프로필 자동 전환.
```

---

## 2. 자세한 설명 (4,000자 제한)

```
자동탭(오토클릭)은 화면의 원하는 위치를 자동으로 터치해주는 안드로이드 오토클리커입니다.
루팅이나 PC 연결 없이, 접근성 권한만 켜면 바로 사용할 수 있습니다.

같은 자리를 계속 누르는 연타부터, 여러 버튼을 순서대로 누르는 복잡한 터치 시퀀스까지
설정해두고 재생 버튼 한 번으로 실행하세요.


■ 주요 기능

• 멀티 포인트 클릭 — 최대 50개의 클릭 포인트를 순서대로 자동 실행
• 터치 녹화 — 직접 터치한 동작을 녹화해 그대로 재생
• 스와이프 & 롱프레스 — 탭뿐 아니라 스와이프, 길게 누르기 지원 (스와이프 경유점 포함)
• 딜레이 단위 선택 — ms·초·분 중 편한 단위로 입력 (10분 대기도 간단하게)
• 포인트별 반복 — 같은 자리를 여러 번 누르기, 반복 간 간격도 따로 설정
• 전체 반복 — 무한 반복 / 횟수 지정 / 시간 지정(초·분·시간)
• 랜덤 오차 — 딜레이와 좌표에 랜덤 오차를 주어 더 자연스러운 동작
• 색상 트리거 — 지정한 색이 감지될 때만 누르는 조건부 자동화
• 이미지 영역 트리거 — 화면 영역을 캡처해 일치할 때만 실행
• 프로필 관리 — 설정을 프로필로 저장·불러오기, JSON 파일로 내보내기·가져오기
• 앱 연동 — 연동한 앱을 실행하면 해당 프로필이 자동으로 로드
• 오버레이 컨트롤 — 다른 앱 위에서 바로 시작·정지, 포인트 추가·이동
• 빠른 토글 — 알림창 타일과 볼륨 버튼 핫키로 즉시 시작·정지
• 통계 — 실행 횟수와 기록 확인


■ 이런 분께 추천

• 게임 반복 퀘스트, 파밍을 자동화하고 싶은 분
• 출석 체크나 수집 버튼처럼 같은 자리를 계속 눌러야 하는 분
• 여러 버튼을 정해진 순서로 눌러야 하는 반복 작업이 있는 분
• 앱 테스트용으로 동일한 터치를 반복해야 하는 분


■ 사용법 (3분이면 충분합니다)

1. 접근성 권한을 켭니다 — 자동 터치를 위해 반드시 필요합니다
2. 다른 앱 위에 표시를 허용합니다 — 게임 위에서 바로 조작할 수 있습니다
3. 포인트를 추가하고 마커를 원하는 자리로 드래그하거나, 터치 녹화로 한 번에 등록합니다
4. 딜레이와 반복 횟수를 정하고 재생 버튼을 누릅니다

정지는 오버레이 패널, 알림창 타일, 볼륨 버튼 어디서든 가능합니다.


■ 무료 / 프리미엄

무료로도 기본 자동 클릭은 모두 사용할 수 있습니다.
• 무료: 클릭 포인트 3개, 프로필 2개, 탭·롱프레스·스와이프, 터치 녹화, 랜덤 딜레이, 오버레이 조작
• 프리미엄: 포인트·프로필 개수 제한 해제, 색상 트리거, 이미지 영역 트리거, 루프 종료 조건,
  프로필 퀵 전환 버튼, 광고 제거

프리미엄은 구독이 아닌 일회 결제입니다.


■ 알아두실 점

• 자동 클릭은 화면이 켜져 있을 때만 동작합니다
• 좌표는 화면 방향별로 다릅니다. 가로에서 만든 프로필은 가로에서 불러오세요
  (방향이 다르면 앱이 안내 메시지를 표시합니다)
• 자동화 도구 사용을 제한하는 서비스가 있습니다. 이용 약관을 확인하고 사용해 주세요
• Android 8.0 이상 지원


[접근성 서비스 사용 고지]
본 앱은 사용자가 지정한 화면 위치를 자동으로 탭/스와이프하는 자동 클릭
기능을 제공하기 위해 Android 접근성 서비스(AccessibilityService API)를
사용합니다.

• 사용 목적: 사용자가 설정한 좌표·순서·반복에 따라 화면을 자동으로
  터치(탭, 롱프레스, 스와이프)하는 동작을 수행하기 위함입니다.
• 접근성 서비스는 사용자가 직접 활성화한 경우에만 동작하며, 자동 클릭
  실행에만 사용됩니다.
• 본 앱은 접근성 서비스를 통해 개인정보나 화면의 콘텐츠를 수집·저장·
  전송하지 않습니다.
• 접근성 권한은 설정에서 언제든지 해제할 수 있습니다.
```

---

## 메모

- **[접근성 서비스 사용 고지] 블록은 반드시 유지하세요.** 접근성 API를 쓰는 앱은 Play 정책상
  용도 고지가 필요하며, 기존 등록본에 있던 문구를 그대로 가져왔습니다.
- 기존 설명 대비 추가한 내용: 딜레이 단위(ms·초·분), 반복 간 딜레이, 이미지 영역 트리거,
  전체 반복 모드, 볼륨 버튼 핫키, 통계, 사용법 단계, 화면 방향 주의, 무료/프리미엄 구분.
- 검색 노출을 위해 "오토클리커 / 오토클릭 / 자동 터치 / 반복 / 매크로 / 루팅 없이" 표현을
  제목이 아닌 본문 안에 자연스럽게 배치했습니다. 키워드 나열식 문구는 Play 정책 위반이라
  문장 안에 녹였습니다.
- 스크린샷 캡션에도 "멀티 포인트", "터치 녹화", "색상 트리거" 같은 기능명을 넣으면 좋습니다.
