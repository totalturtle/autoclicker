아트보드를 선택하고 내보내기(PNG)를 누르면 지정한 크기 그대로 저장됩니다.

## 1. 교체 대상

| 자리 | 지금 올라가 있는 것 | 새로 올릴 것 |
|---|---|---|
| 스크린샷 1 | 간단 모드 (새 스타일) | 그대로 둠 |
| 스크린샷 2 | 앱별 프로필 (예전 UI·어두운 초록) | `스토어 스크린샷 2 · 모든 기능` |
| 스크린샷 3 | 화면 위에서 제어 (예전 UI·보라) | `스토어 스크린샷 3 · 앱 위에서 제어` |
| 스크린샷 4 | 반복 작업 (예전 UI·검정) | 지우거나, 나중에 녹화 화면으로 교체 |
| 피처 그래픽 | 예전 보라색 배너 | `피처 그래픽 A` 또는 `B` 중 하나 |

스크린샷은 1080×1920, 피처 그래픽은 1024×500입니다.

## 2. 피처 그래픽 두 가지 안

- **A · 문구형** — "누를 위치만 정하면 끝, 새로워진 간단 모드".
  스크린샷 1번과 문구가 같아서 목록 상단부터 메시지가 이어집니다.
- **B · 앱이름형** — "자동탭 · 오토클릭" + 한 줄 설명 + 칩 세 개.
  배너답게 앱 이름이 먼저 읽히고, 검색 결과에서 브랜드가 남습니다.

둘 중 하나만 올리면 됩니다. 고르기 어려우면 B를 권합니다 —
피처 그래픽은 목록 맨 위 배너라서 앱 이름이 보이는 쪽이 유리합니다.

## 3. Play Console 올리는 자리

Play Console → 앱 선택 → **사용자 늘리기 → 스토어 등록정보 → 기본 등록정보**

- **그래픽** 섹션 → 앱 아이콘 / 그래픽 이미지(피처) / 휴대전화 스크린샷
- 스크린샷은 올린 뒤 끌어서 순서를 바꿀 수 있습니다. 1번이 간단 모드로 남게 하세요.
- 저장하면 검토를 거쳐 몇 시간 안에 반영됩니다. 앱 출시와는 별개입니다.
